# Brand capability research map

The pack is synthesized from the following source classes. It does not copy source text, prompts, or
protected templates.

## Primary references

- [Anthropic: encode a brand as a skill](https://academy.claude.com/use-cases/brand-guidelines-skill)
- [Anthropic: create a design system](https://academy.claude.com/tutorials/create-a-design-system-with-claude)
- [W3C SVG](https://www.w3.org/Graphics/SVG/About)
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)
- [Google Fonts](https://developers.google.com/fonts)

## Open implementations studied

- [brand-identity-skill](https://github.com/fatihaydost/brand-identity-skill): measurable identity sets,
  small-size checks, licenses, and delivery kits.
- [claude-illustrate-skill](https://github.com/code-katz/claude-illustrate-skill): asset-class routing,
  SVG-first marks, contact sheets, and provenance.
- [brand-kit](https://github.com/irgiahmadm/brand-kit): staged discovery, user checkpoints, brand books,
  tokens, and implementation.

These are pattern sources, not dependencies. Their licenses, maturity, and bundled references differ;
their code and reference assets are not copied into Domo.

## Video workflow evidence

Videos are treated as experiments to reproduce, not authority. The initial evidence set includes:

- [Adobe Live: building custom design tools with Claude Code](https://www.youtube.com/watch?v=y5J8M82um90)
- [Claude Design professional design walkthrough](https://www.youtube.com/watch?v=Z90zSsooYEw)
- [Claude Design and Figma workflow](https://www.youtube.com/watch?v=UbECXhiYdMQ)

Extract only repeatable techniques: provide real brand context, establish a design system before
applications, generate multiple directions, convert approved work to editable source, iterate against
the artifact, and export a reusable system. Do not copy creator prompts verbatim or add a paid tool
because a video promotes it.

## Selection rule

A technique enters the pack only when it improves at least one of these in a fixed benchmark:

- strategic coherence;
- distinctiveness;
- copy clarity;
- visual consistency;
- technical correctness;
- provenance completeness;
- user decision friction.
