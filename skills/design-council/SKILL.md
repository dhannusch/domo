# Design council

1. **Frame**: write a one-paragraph brief covering the goal, the constraints, the user and what "good" means. Ask the user only if a missing constraint would change everything.
2. **Diverge**: call `council` with 3–5 models across both providers, with `rounds: 2`. Each model proposes independently, with no shared context beyond the brief. Ask for genuinely different directions, not variations.
3. **Blind critique**: in round 2, each model critiques the others' anonymized proposals against the brief and names what to steal.
4. **Converge**: you synthesize. Present **2 options plus your recommendation** as a Comparison with at most 4 attributes. Name the dissent in one line.
5. **Decide**: offer a Choice. Once the user chooses, refine only the chosen direction.

Keep the debate behind "view". The user sees one sentence, the Comparison, and the Choice.
