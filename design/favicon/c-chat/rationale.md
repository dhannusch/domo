# C · Open arch

Status: proposed, unapproved. Revised after pixel critique.

Mechanism: one broad arch with an open base and an intentionally shorter right leg. It suggests an accessible place to return to, rather than drawing a messaging control or a mascot. The quiet-place association is a creative hypothesis, not an approved positioning claim.

Mark idea: a sturdy single-piece threshold. The large open counter keeps the silhouette calm and legible. The asymmetric leg is the only unusual event, avoiding both a generic closed doorway and an ornamental tail. It has no roof, house outline, crossbar, arrowhead or enclosing bubble.

Palette/type roles: graphite #292929 on Chalk #f5f5f5; exact reversal for dark grounds. No text or font is embedded in the symbol. Supporting UI keeps its existing typography.

Application: app.svg is a full square for PWA masking; reversed.svg is the dark tile; symbol.svg is transparent; small.svg is optically redrawn for a tab.

Distinction: an architectural, place-like silhouette rather than A's initial or B's paper object. It is deliberately more abstract than a chat bubble.

Worst risk: an arch can read as a lowercase n, doorway or a hospitality/architecture mark. The user must prefer the quieter place association over immediate Domo name recognition. This remains less literal than A.

Geometry: main ink bounds x64–192, y56–200. The farthest possible bounding-box corner has radius sqrt(64²+72²)=96.33px from center128,128, below the102.4px maskable safe-circle radius. Background fills the full canvas, so no separate maskable version is needed. The32px legs survive at16 as2px when reducing the main symbol.

Small-size changes: optical art uses x3–13,y2–14 and2.5px legs. The counter is5px wide; shorter leg ends at12 instead of14. Pixel review should verify the shorter leg stays intentional rather than looking accidentally clipped.

## Critique and revision

The first proposal was an open conversation loop with an inward return. Parent-rendered first-board.png made it read unmistakably as G/return, so the concept was rejected before presentation. The revised arch removes the crossbar and arrow-like return entirely. This is a substantial new silhouette, not a cosmetic smoothing of the weak direction. No production asset was changed.

Provenance: directly authored editable SVG geometry in this task, November21,2026. No external art, font, raster image, traced mark, filters, scripts or gradients. Original project work, with no trademark or legal-clearance claim. User approval is pending.
