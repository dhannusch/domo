# SVG icon directions

Read brand-pack/foundation.md, voice.md and graphic-language.md first. This is a scoped icon refinement using an approved existing product/UI foundation. Do not edit production files or scripts/make-icons.ts.

Own only your assigned direction folder under design/favicon/. Write symbol.svg (transparent 256×256 viewBox, authored geometry in #292929), app.svg (same symbol on #f5f5f5 full square), reversed.svg (paper symbol on #292929 full square), small.svg (16×16 viewBox optical favicon), and rationale.md. Use no fonts, images, external URLs, scripts, gradients, filters or clip paths. Keep geometry simple. Never trace an existing recognizable mark. Mark all proposals unapproved. Give main mark bounds and explain maskable safety (central safe circle radius102.4 at256; full background unmasked square). If a direction needs a distinct maskable source provide maskable.svg too.

A Custom d: bespoke lowercase monogram, readable at16, personal tool and modest typography; avoid a default font glyph.
B Fold: folded note/page gesture, abstract, quiet and document-like; avoid a generic file outline.
C Conversation: one continuous compact conversational shape, conveying one chat without stacked speech bubbles; avoid infinity knots, AI sparkles or generic messenger logos.

Each rationale: mechanism, mark idea, palette/type roles, application, distinction, risk, exact bounds, small-size changes, provenance (authored SVG, no external assets). Then critique the other directions once available and write critique.md in your folder. Parent renders boards with 16/24/32/64/128/256px and tab/PWA applications; do not launch browsers. Parent will send screenshots for pixel review.
