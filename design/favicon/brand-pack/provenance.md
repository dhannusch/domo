# Icon asset provenance

All symbols are directly authored SVG paths by the three design subagents in this chat, based on the existing Domo product brief and the user-selected Chalk palette. No diffusion image, stock art, traced logo or font glyph was used in the marks. The SVGs remain editable.

The board uses Instrument Sans Variable from the existing project dependency, licensed under SIL Open Font License; a copy is in ../assets/Instrument-Sans-LICENSE.txt. The current icon reference is copied from apps/web/public/icons/icon-512.png and is existing project artwork. Browser/PWA frames on the board are schematic context, not screenshots of native OS chrome.

PNG previews were rendered from SVG in Chrome using Playwright. Small optical SVGs are used at16/24/32px; main symbols at64/128/256px. Reversed transparent variants are direct color substitutions of the same paths. manifest.json records paths, status and SHA256 hashes. All new marks remain proposed pending user choice.

No trademark similarity search or legal clearance is claimed. Font license applies only to the board's supporting text, not the custom mark geometry.
