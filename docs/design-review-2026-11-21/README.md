# Domo UI design review

Research → fresh live-app audit → four independent directions → peer critique → revised rendered gallery. The user selected refined Soft Focus in Chalk. It is now implemented in the web app. See [implementation and checks](implementation.md). The original studies remain below for reference.

[Open the neutral palette study](palettes/index.html).

[Open the gallery](index.html). Run the local server in [validation.md](validation.md) for interactive previews.

| Direction | Focus | Tradeoff |
|---|---|---|
| A Correspondence | Open, editorial reading | More vertical space |
| B Quiet Utility | Compact decisions and work | More utilitarian |
| C Soft Focus | Comfortable phone interactions | Larger tactile surfaces |
| D Folio | Durable documents and provenance | More formal framing |

All directions include main chat, six components, settings, file viewer and interaction state specimens. Captures cover 375px/1440px and both themes; checks also cover 320px.
