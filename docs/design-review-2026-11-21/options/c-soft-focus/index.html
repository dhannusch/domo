A quieter way to plan

A short note about making room for work that matters, without filling every spare hour.

1. Start with one good idea

Choose a question that stayed with you this week. Open with the moment that made it feel useful.

2. Leave something out

Three short sections are enough. Give each one a clear point and a little room to breathe.

3. Keep the weekend free

Draft on Tuesday. Edit on Thursday. Send when the issue feels ready.
